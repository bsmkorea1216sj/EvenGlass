# EvenGlass G2 대화 답변 추천 시스템 아키텍처 (초안)

> 출처: 2026-11-25 메일 「[EvenGlass] G2 대화 답변 추천 시스템 아키텍처」를 정리. 맨 끝에 0.5.0 프로토타입 구현 현황을 덧붙였다.

## 1. 목표
- 외국인이 말하면 G2 안경이 언어를 자동 감지해 번역을 보여준다.
- 동시에 휴대폰 앱이 SJK 본인 말투로 된 예상 답변 2개를 상대 언어로 G2 화면에 띄운다.
- 선택 동작 없이, 마음에 드는 답을 보고 그대로 말한다.

## 2. 화면 표시 형식 (답 1개당)
| 상대 언어 | 줄 수 | 내용 |
|---|---|---|
| 영어 | 2줄 | 원문 / 한국어 뜻 |
| 그 외 | 3줄 | 원문 / 한국어 뜻 / 한글 발음 (예: そうですね / 그렇네요 / 소-데스네) |

- G2 화면이 작으므로 답은 1~2문장으로 제한한다.

## 3. 사전 준비 (PC 또는 서버, 주기적으로 실행)
1. **데이터 수집**: Claude 대화 내보내기 + G2에 쌓인 실제 대화 기록
2. **정리**: 상대 발화 / 본인 답변을 한 묶음으로 자르고 개인정보 제거
3. **말투 프로필**: 본인 답변에서 어휘, 길이, 존댓말 정도, 자주 쓰는 표현을 짧은 설명서로 추출
4. **임베딩**: 휴대폰에서도 돌아가는 소형 다국어 임베딩 모델로 벡터화 (사전 준비와 휴대폰에서 반드시 같은 모델 사용)
5. **패키징**: SQLite(벡터 + 원문) 파일과 말투 프로필을 앱이 내려받음

## 4. 휴대폰 앱 구성
```
[입력부] G2 번역 기능(상대 원문 + 감지 언어)  ─ 불가하면 → 자체 스트리밍 음성 인식
   │
[검색부] 기기 안 임베딩 → 키워드 + 벡터 하이브리드 검색 → 유사 대화 상위 5개 (수십 ms)
   │
[생성부] 검색 결과 + 말투 프로필 + 상대 원문 → Gemini Flash
         출력 JSON {lang, answers:[{text, ko_meaning, ko_pron}]} (영어면 ko_pron 생략)
         인터넷이 안 되면 Gemini Nano(온디바이스)로 대체
   │
[출력부] G2 SDK로 답 2개 표시, 첫 답부터 스트리밍 표시
```

## 5. 고도화 순환 구조 (리사이클링)
- 매 대화마다 상대 원문, 제시된 답 2개, 실제로 내가 말한 답을 기록한다.
- 내가 말한 답이 제시안 중 하나면 그 답을 좋은 예시로, 둘 다 아니면 내가 직접 한 답을 정답 예시로 저장한다.
- 주기적으로 3번 사전 준비를 다시 돌려 벡터 DB와 말투 프로필을 갱신 → 앱에 재배포한다.
- 데이터가 충분히 쌓이면 Gemini 튜닝(파인튜닝)을 검토한다.

## 6. 예상 반응 속도 (상대 말이 끝난 뒤)
| 단계 | 시간 |
|---|---|
| 언어 감지·인식 확정 | 0.5~1초 |
| 검색 | 0.1초 |
| Gemini 생성 | 약 1초 |
| G2 표시 | 0.2초 |
| **합계** | **약 1.5~2.5초** |

단축 방안: 중간 인식 결과로 검색을 미리 실행, 스트리밍 생성, 자주 나오는 질문의 답은 캐시.

## 7. 확인이 필요한 사항
- G2 기본 번역 앱의 결과를 외부 앱이 받을 수 있는지, Even Realities SDK가 화면 출력과 대화 기록 내보내기를 지원하는지.
- 상대방 음성을 녹음·처리하므로 **상대 동의 및 고지 필요**.
